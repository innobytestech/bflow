# Installation

## Requirements

- **Claude Code 2.1.271 or later**, if you use it as an agent (`bflow doctor` checks the version). **OpenCode**, if you use it as an agent.
- **Go 1.25 or later**, only for `go install` or compiling from source. The installers do not require Go.
- git. For PRs with GitHub, a token (see [configuration](configuration.md)).

## Install

Installed once per machine. Each repository only needs a short `bflow.yaml`; no bflow code is ever copied into the repository.

Linux and macOS (in `~/.local/bin`; `BFLOW_INSTALL_DIR` changes the directory):

```bash
curl -fsSL https://raw.githubusercontent.com/innobytestech/bflow/main/install.sh | sh
```

Windows (in `%LOCALAPPDATA%\Programs\bflow`, which adds to your `PATH`; `BFLOW_INSTALL_DIR` changes the directory):

```powershell
irm https://raw.githubusercontent.com/innobytestech/bflow/main/install.ps1 | iex
```

On Windows, `BFLOW_INSTALL_NO_PATH=1` prevents the script from modifying your `PATH`.

### Pinning a version

The scripts install the latest stable version. `BFLOW_VERSION` pins a specific version, with or without `v`:

```bash
curl -fsSL https://raw.githubusercontent.com/innobytestech/bflow/main/install.sh | BFLOW_VERSION=v0.1.0 sh
```

```powershell
$env:BFLOW_VERSION = 'v0.1.0'; irm https://raw.githubusercontent.com/innobytestech/bflow/main/install.ps1 | iex
```

### Verifying your download

Both scripts verify the SHA-256 of the archive against `checksums.txt` before installing. You can also download the archive for your platform from [Releases](https://github.com/innobytestech/bflow/releases). Each release comes with provenance attestation:

```bash
gh attestation verify <archive> --repo innobytestech/bflow
```

This verifies it was built by the repository's workflow.

### With Go or from source

```bash
go install innobytes.tech/bflow/cmd/bflow@latest
```

```bash
git clone https://github.com/innobytestech/bflow.git
cd bflow
go install ./cmd/bflow
```

## Verifying installation

```bash
bflow version    # prints version
bflow doctor     # validates config, tools, connections, environment, and hooks
```

If `bflow` is not found, the installation directory is not in your `PATH`.

## Installing in your agent tool

Inside the repo:

```bash
bflow install claude      # or: bflow install opencode
```

- **Claude Code:** installs the skill in `~/.claude/skills/bflow/SKILL.md` (once per machine), merges hooks, permissions, and status bar into `<repo>/.claude/settings.json` without touching your existing settings, and runs `bflow render` if the repo has `agent: claude`.
- **OpenCode:** places the `/bflow` command in `$XDG_CONFIG_HOME/opencode/commands/bflow.md` (or `~/.config/opencode/commands/bflow.md`); with `opencode` under `agent:` it also runs `render`, which writes agents and the plugin to `.opencode/`.
- It is idempotent: run it again whenever you want. `--skill-only` installs only the skill or command.

Details (hooks, plugin, OpenCode models) are in [configuration](configuration.md#claude-code-and-opencode).

## Updating

```bash
bflow update            # updates to the latest published release
bflow update --check    # only checks if a new version exists
bflow update --force    # replaces even if this binary is not from a published release (e.g. self-compiled)
```

`bflow update` selects the channel based on what is currently installed: with a prerelease you get the next one (for example, from `v0.1.0-rc.10` to `v0.1.0`); with a stable version you never receive prereleases. It also refreshes the Claude Code skill and OpenCode command if they were already installed.

## Uninstalling

There is no `uninstall` command. Manually:

1. Delete the `bflow` binary (from the installation directory above).
2. Delete the skill: `~/.claude/skills/bflow` and, if using OpenCode, `bflow.md` in OpenCode's `commands` folder.
3. In each repo, remove bflow entries from `.claude/settings.json` (hooks, permissions, status bar).
4. Delete files generated by `bflow render`: `bflow-*.md` files in `.claude/agents/` and `.opencode/agents/`, `.opencode/plugins/bflow.js`, `.opencode/plugins/bflow2/`, and the bflow block in `AGENTS.md`.
5. Delete `bflow.yaml` and the `.bflow/` directory in the repo, and global config (`~/.config/bflow/`, on Windows `%AppData%\bflow\`) if no longer needed.
6. Remove credentials from system keychain (Credential Manager, Keychain, or Secret Service) stored by `bflow connect`.
